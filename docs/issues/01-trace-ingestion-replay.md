## Problem & Context
The current evaluation framework (`src/evaluation.ts::evaluate`) exclusively supports forward execution: initiating a test trial from zero, running an adapter, waiting for the agent to finish, and verifying static outputs. However, in production scenarios:
1. **Trace Disconnection**: Real-world user sessions, agent failure trajectories, and OTel traces cannot be directly ingested or fed into the evaluation harness without re-running the agent.
2. **Expensive Verification Iteration**: Modifying or calibrating criteria/verifiers requires re-running LLMs/agents, which is costly, slow, and non-deterministic.
3. **Lack of Automated Case Generation**: `src/scaffold.ts::feedbackSource` only supports extracting evidence from local `result.json` files generated by previous runs, but cannot convert an external production trace into an executable test case.

## Proposed Design
1. **Unified Trace Format**:
   - Define a standard `UnifiedTrace` schema in `src/types.ts` capturing multi-turn steps, timestamps, roles, thoughts/reasoning, tool calls, and tool outputs.
   - Provide an ingestion adapter/parser for common trace formats (e.g., OpenTelemetry, AgentOS JSONL, LangSmith).
2. **Offline Replay Engine**:
   - Add `--agent replay --trace <path>` execution mode in `src/runner.ts` and `src/evaluation.ts`.
   - Replay skips external model calls, re-materializes the trajectory events into `events.jsonl` and `workspace/`, and passes frozen artifacts to `src/verifier.ts` for instant verification.
3. **Trace-to-Case Scaffolding CLI**:
   - Add CLI command `pnpm eval case from-trace <trace.json> --requirement <id> --suite <suite>`.
   - Automatically extract public inputs (`input.json`, mock `fixture.json`) and private expectations into a runnable case structure.

## Acceptance Criteria
- [ ] Ingests standard JSONL trace logs into a typed `UnifiedTrace` object.
- [ ] Offline replay executes in <100ms with zero network/API calls, producing identical event logs and verifier outcomes.
- [ ] CLI command `eval case from-trace` generates a valid schema v2 case directory passing `pnpm eval validate --schema-only`.
